Fruit Freshness Detection

Tools: Python, TensorFlow/Keras, EfficientNetB0, pandas, scikit-learn

96,1%akurasi validasi, 26 kelas, 14.264 gambar
Problem
Mengklasifikasikan kesegaran buah dan sayur dari gambar: 13 jenis, masing-masing segar atau busuk (26 kelas), memakai dataset food-freshness dari Kaggle. Jumlah gambar per kelas sangat tidak seimbang, dari 327 sampai 13.681.
Approach
Transfer learning dengan EfficientNetB0 (pretrained ImageNet) dalam dua tahap: backbone dibekukan, lalu 30 layer teratas di-fine-tune dengan learning rate kecil. Data dibagi 80/20 terstratifikasi (57.054 latih, 14.264 validasi), dengan augmentasi gambar, class weight (kelas busuk diberi bobot ekstra), dropout, BatchNorm, dan regularisasi L2.
Result
Pada set validasi: akurasi 96,1%, precision 96,4%, dan recall 95,8%. Fine-tuning menaikkan recall dari 91,4% menjadi 95,8%. Angka ini berasal dari set validasi, belum ada test set terpisah.

Pemilik proyek tugas akhir. Notebook mencakup pipeline data, arsitektur model, training dua tahap, dan evaluasi.
