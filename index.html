Fruit Freshness Detection

Tools: Python, TensorFlow/Keras, EfficientNetB0, pandas, scikit-learn

97,7%akurasi test set, 26 kelas, 10.698 gambar
Problem
Mengklasifikasikan kesegaran buah dan sayur dari gambar: 13 jenis, masing-masing segar atau busuk (26 kelas), memakai dataset food-freshness dari Kaggle (71.318 gambar). Jumlah gambar per kelas sangat tidak seimbang, dari 327 sampai 13.681.
Approach
Transfer learning dengan EfficientNetB0 (pretrained ImageNet) dalam dua tahap: training classification head dengan backbone dibekukan (8 epoch), lalu fine-tuning 47 layer teratas dengan learning rate 2e-5 (12 epoch). Data dibagi 70/15/15 terstratifikasi (49.922 latih, 10.698 validasi, 10.698 test). Validasi dipakai untuk early stopping dan memilih threshold, test set hanya dipakai sekali di akhir. Teknik lain: augmentasi gambar dan class weight dengan bobot ekstra untuk kelas busuk.
Result
Pada test set: akurasi 97,7% dan macro F1 0,971. Dalam tampilan Fresh vs Rotten, 98,2% buah busuk terdeteksi (3.533 dari 3.596) dengan precision 96,2%. Fine-tuning menaikkan akurasi validasi dari 96,5% menjadi 97,6%. Dengan threshold yang dipilih di data validasi, precision buah busuk naik ke 98,8% tetapi recall turun ke 94,8%, sedikit di bawah target 95%. Latensi P95 11,6 ms per gambar (GPU Colab, hanya model).
Kelemahan
Recall terendah ada pada RottenBellpepper (83,1%, 89 gambar). Ada juga 85 gambar FreshOrange yang diprediksi RottenOrange. Test set berasal dari dataset yang sama dengan data latih, jadi model belum diuji pada foto dari kamera sungguhan.
