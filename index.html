Credit Score Prediction

Pythonpandasscikit-learnRandom ForestStreamlit
Problem
Mengembangkan model machine learning untuk mengklasifikasikan kategori credit score berdasarkan data yang tersedia (dataset 25.000 baris).
Approach
Python, pandas, dan scikit-learn untuk pengolahan data, dan Random Forest untuk klasifikasi. Model disimpan dalam format .pkl dan disiapkan untuk integrasi dengan aplikasi Streamlit.
Result
Akurasi 74% pada evaluasi yang dilakukan.
My Contribution
Pengolahan data, pengembangan model, evaluasi performa, dan persiapan deployment.
